# 最小化改为正常缩到任务栏 - 设计文档

**日期**: 2026-10-09
**版本**: v1.7.3 → v1.7.4

## 1. 背景

Popup 当前点击最小化按钮时，会通过 `changeEvent` 把窗口 `hide()` 缩到系统托盘（而非正常最小化到任务栏）。用户反馈该行为不符合预期，希望最小化按正常方式处理（缩到任务栏，点击任务栏图标恢复）。点 X 缩到托盘的行为保留不变。

## 2. 目标行为

| 操作 | 当前行为 | 目标行为 |
|------|---------|---------|
| 点击最小化按钮 | 窗口隐藏，缩到系统托盘 | 正常最小化，缩到任务栏 |
| 点击任务栏图标 | 无（窗口已隐藏，任务栏无图标） | 恢复最小化的窗口 |
| 点击 X 关闭按钮 | 缩到系统托盘 | 缩到系统托盘（**不变**） |
| 双击托盘图标 | 恢复窗口 | 恢复窗口（**不变**） |
| 右键托盘图标 → 退出 | 退出进程 | 退出进程（**不变**） |

## 3. 技术方案

### 3.1 架构

所有行为改动集中在 `md_viewer.py`。核心是删除唯一让「最小化 → 缩托盘」生效的 `changeEvent` 重写，让最小化回归 Qt 默认行为。

### 3.2 改动点

**`md_viewer.py`**

1. **删除 `changeEvent` 方法**（当前位于 `md_viewer.py:738-744`）：

```python
    def changeEvent(self, event):
        """重写状态变更事件：最小化时缩到托盘。"""
        if event.type() == QEvent.Type.WindowStateChange:
            if self.windowState() & Qt.WindowState.WindowMinimized:
                self._save_window_geometry()
                self.hide()
        super().changeEvent(event)
```

整段删除。删除后最小化走 Qt 默认路径：窗口正常缩到任务栏。

2. **`_save_window_geometry` 保留**：`closeEvent`（点 X 缩托盘）仍在调用它保存几何，不受影响。

3. **其余不动**：`closeEvent`、`init_tray`、`on_tray_activated`、`restore_window`、`showEvent`、`quit_app` 全部保留。

### 3.3 与置顶开关的交互

最小化/恢复不改变 HWND 的 topmost 属性，`showEvent` 只在 `show()` 时触发。正常最小化→任务栏恢复走的是 `WindowStateChange`（Minimized → Normal），不经过 `showEvent`，但置顶状态由 `SetWindowPos` 设置在 HWND 上、在最小化/恢复间保持，因此恢复后置顶状态不变。无需额外处理。
